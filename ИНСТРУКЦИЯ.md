# OzonPilot — инструкция для продавца

**OzonPilot** (`OzonPilot.exe`) отвечает на вопрос: что и в каком количестве везти на склады Ozon, где товар заканчивается и сколько стоит хранение.

## Где результат

Рядом с exe появится папка `reports`, в ней файл `ozon_supply_ГОД-МЕСЯЦ-ДЕНЬ_ЧАС-МИНУТА.xlsx`. Открывается в Excel; внутри два листа:

* **«Поставки»** — сама таблица с фильтрами по заголовкам;
* **«Легенда»** — расшифровка всех цветов.

## Как читать отчёт

* Каждый кластер — свой цвет: три колонки кластера (продажи, остаток на FBO, рекомендуемая поставка) залиты одной гаммой. Смотреть нужно на колонку **«Поставка FBO»** — это и есть ответ, сколько везти.
* **«Размещение FBO»**: `Платно` — красный (за хранение списывают деньги), `Бесплатно (до ДД.ММ.ГГГГ)` — жёлтый (льготный период заканчивается), `Бесплатно` — зелёный, `-` — серый (товара на FBO нет).
* **Деньги за хранение** — две колонки: «Списано за хранение (₽)» (что Ozon уже списал за последние 28 дней) и прогноз («на 28 дн.» и «до конца месяца»). Это цифры Ozon из выгрузки личного кабинета. Суммы краснеют, если больше нуля.
* Если выгрузки ЛК нет и данные берутся только из API, вместо прогноза Ozon выводится одна колонка **«Оценка хранения за 30 дн. (₽)»** — это расчёт программы, он может отличаться от Ozon в 2–4 раза.
* Если денежные колонки пустые, а в титуле написано `ВНИМАНИЕ: данные о размещении Ozon не получены` — значит, отчёт о размещении не загрузился; смотрите раздел «Если что-то не работает».
* **«Статус»** — итог по товару:
  * `OUT_OF_STOCK` — закончился везде при живом спросе, упущенная прибыль;
  * `NEEDS_FBO` — на складах Ozon дефицит, нужна поставка;
  * `NEEDS_FBS` — пусто на вашем собственном складе;
  * `OK` — запаса хватает.

Строки отсортированы по срочности: сверху то, что требует действий в первую очередь.

## Полезные ключи запуска

| Ключ | Что делает |
|:---|:---|
| `-postavka 30` | на сколько дней вперёд обеспечить запас (по умолчанию 25). Можно `mounth` или `quarter` |
| `-prodazhi 60` | за сколько дней анализировать продажи (по умолчанию 28). Можно `mounth` или `quarter` |
| `-clusters "Москва,Санкт-Петербург"` | считать только эти кластеры, `-clusters all` — все |
| `-placement-file "файл.xlsx"` | взять размещение и прогноз Ozon из выгрузки ЛК «Стоимость размещения по товарам» (самый точный вариант) |
| `-report-timeout 10` | сколько минут ждать отчёт Ozon от API (по умолчанию 5) |
| `-reset-keys` | забыть сохранённые ключи и ввести новые |
| `-debug` | подробный лог запросов, если что-то идёт не так |

Пример:

```powershell
.\OzonPilot.exe -postavka 30 -prodazhi 60 -clusters all
.\OzonPilot.exe -placement-file "C:\Users\Ты\Downloads\Стоимость размещения по товарам.xlsx"
```

## Если что-то не работает

| Что видите | Что делать |
|:---|:---|
| Синее окно SmartScreen | «Подробнее» → «Выполнить в любом случае». Это не вирус, просто exe без цифровой подписи. |
| `Ошибка авторизации Ozon`, `unexpected API status code: 401/403` | Ключи неверные или у ключа нет прав «Администратор»/«Аналитика». Исправьте права в кабинете Ozon или запустите `-reset-keys` и введите ключи заново. |
| `не удалось создать папку отчетов` | exe лежит там, куда нельзя писать (например, `Program Files`). Перенесите его в свою папку. |
| `WARN Не удалось обновить файл конфигурации` | Файл с ключами защищён от записи, но программа продолжит работу с ними. На отчёт не влияет. |
| Окно мигнуло и закрылось | Запускайте из терминала, а не двойным кликом, — тогда текст ошибки останется на экране. |
| Отчёт не появился, ошибка `не для всех товаров` | Ozon не отдал часть данных (лимиты или сбой). Просто запустите ещё раз. |
| Денежные колонки пустые, в титуле `ВНИМАНИЕ: данные о размещении Ozon не получены` | Отчёт о размещении не пришёл от API. Запустите ещё раз (сервис ждёт до 5 минут и повторяет запрос) или передайте выгрузку ЛК: `-placement-file "Стоимость размещения по товарам.xlsx"`. |
| В колонке оценки ярко-синие ячейки | Это отчёт из старой версии. Сформируйте отчёт заново текущим `OzonPilot.exe`. |

## Про ключи

Ключи лежат в открытом виде в файле `%APPDATA%\CLIForOZON\config.yaml` — не пересылайте этот файл никому. Если нужно передать программу коллеге, передавайте только `OzonPilot.exe`: при первом запуске он спросит ключи сам.
